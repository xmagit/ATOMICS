# Linux platform audit

Written by GPT-6 Codex, 2026-10-29.

| Assumption | Linux behavior / compatibility |
| --- | --- |
| `~/Applications`, `.app`, `sips`, `iconutil`, `codesign` | `macos-app.sh` explicitly requires Darwin. `linux-install.sh` builds a native release, atomically installs `~/.local/bin/imacs`, and installs `imacs.desktop`, a scalable icon and a 512px PNG under XDG data storage. Repeated install/uninstall is supported; uninstall keeps state/config. |
| State in `~/.imacs` | Existing directories and symlinks remain authoritative, including offline links. New Linux installs use `$XDG_STATE_HOME/imacs`, defaulting to `~/.local/state/imacs`. macOS keeps its current path. The earlier `.cox` migration remains available. |
| Socket beside state | New Linux installs use a private, owned `$XDG_RUNTIME_DIR/imacs/<home hash>/imacs.sock`; missing, relative, public or unavailable runtime directories fall back to state storage. Existing installs and explicit `IMACS_HOME` retain their socket paths. `IMACS_SOCKET` wins. New socket files have mode 0600. |
| Jobserver under a macOS temporary path | Linux uses `<XDG runtime>/imacs/<home hash>/jobserver/jobserver.fifo` when valid. Otherwise, both platforms retain the existing `std::env::temp_dir()/imacs-<uid>/<home hash>` fallback. No `/private/tmp` dependency. |
| FIFO creation and permissions | `mkfifo(0600)` and read/write opening work on Linux and macOS. Pool directories are created with mode 0700; symlink/foreign-owner checks remain. Existing ancestor permissions are no longer changed. Tests consume tokens and reset leaks, check mode/type and ancestor preservation. Only `CARGO_MAKEFLAGS` carries the FIFO; older GNU make and Apple's make must not inherit it via `MAKEFLAGS`. |
| Sandbox access to `/run/user` | The FIFO lives in its own `jobserver/` subdirectory. Codex gets `--add-dir` only for that directory so sandboxed compilers can open it without write access to the sibling control socket. This preserves user-supplied extra directories. Launch tests check that the socket is outside every generated `--add-dir`; app tests use private temporary XDG runtime storage on Linux. |
| `ps`, `nice`, load average | `ps -axo pid=,ppid=` (ancestry), `ps -axo args=` (compiler detection), `ps -o nice= -p` (tests), `nice -n` and libc `getloadavg` work on procps Linux and macOS. A failed compiler scan conservatively prevents FIFO refill. Real-parent ancestry and inherited niceness have tests. |
| `/bin/zsh` fallback | `$SHELL` is used when nonempty. Without it, Linux uses `/bin/sh`; macOS keeps `/bin/zsh`. Both login-environment discovery and shell terminals use this choice. |
| Host identity via `scutil` | The merged host configuration code calls `/usr/sbin/scutil` only on macOS. Linux uses `gethostname`, with the same sanitized `IMACS_HOST` override and host-specific `config.d` merging. Both sets of path tests are retained after the merge. |
| Config reload timestamps | Linux filesystems can give rapid same-length edits identical mtimes. Polling now fingerprints the two small config files, so host overrides reload even with equal timestamps; the regression test forces that case. |
| Microphone privacy settings | macOS silence errors keep the System Settings microphone hint; Linux points to the default input, mute and desktop audio permissions. Audio uses cpal's platform backend (ALSA on Linux). |
| `open` and bundle restart | Files use `xdg-open` on Linux. Bundle-specific `open -n -a` is only used on macOS; Linux restarts the executable directly. Linux's `/proc/self/exe` deleted-inode suffix after an atomic update is removed when finding the installed replacement, including for hooks and agent launch. A Linux subprocess test replaces its own executable and validates the restart target. |
| App-bundle screenshot executable | `--screenshot` captures through eframe from the same CLI binary on Linux. The Linux Docker harness supplies an isolated HOME/config/state/socket and a virtual display; no app-bundle screenshot path is needed. |
| Window system and fonts | eframe 0.37 enables Wayland, X11, wgpu, system fonts and embedded default fonts. Wayland/X11/default-font features are explicit in the app dependency. No Apple font path is used. Linux desktop identity is `imacs`, matching `imacs.desktop` and its icon. |
| Command shortcuts | The existing parser maps `cmd` to Ctrl+Shift on Linux, applying Shift once. Plain Ctrl stays available to terminals. UI hints now format the same parsed chords as the handler, including configured editor shortcuts. The README gives Linux examples. |
| APFS cache clones | macOS retains native `clonefile`; Linux uses GNU `cp -R --reflink=always`. Linux first rejects special files: GNU cp can recreate socket-only trees even when reflinks are unsupported. btrfs and reflink-enabled XFS can clone on the same filesystem; ordinary ext4, disabled reflinks and cross-filesystem copies fail open to a cold worktree. Staging removes partial clones and there is no full-copy fallback. Native Linux tests verify either independent cloned files/symlinks or a clean skip. Set `IMACS_COW_TEST_DIR` to repeat the native test on a mounted filesystem. |
| macOS-only warm-worktree tests | Clone, doctor and launch-order tests now run on Linux too, account for unsupported reflinks and use an uncloneable socket to force failure even when QA runs as root. |
| QA scripts and old paths | Both .NET budget scripts already use `tempfile` and compatible `ps` flags; they now find a system .NET installation when `~/.dotnet/dotnet` is absent (or honor `DOTNET`). They explain a missing SDK. Docs give Linux `ps eww -p <pid>` syntax. Literal macOS paths in captured fixtures, quoting/parser tests and historical QA evidence remain as data; none are opened as live QA paths. Heartbeat's `date` test already selects BSD `-r` versus GNU `-d`. |

For fresh Debian/Ubuntu installations, the README lists build libraries, Mesa runtime support and desktop portal/`xdg-open` integration. CI already runs Linux by default with its native library dependencies; macOS remains an opt-in runner.

## Validation

Validated on 2026-10-29 in the merged Docker harness: Debian bookworm, Rust 1.98.0, `aarch64-unknown-linux-gnu`, two CPUs, source mounted read-only at `/repo`, build output in `/target`. `main` was already up to date; the integration merge retained host identity, path expansion tests and `config.d` merging. The image now installs Clippy and rustfmt for subsequent reviewers.

- Linux `cargo check --workspace --all-targets --locked`, `cargo fmt --all --check`, and `cargo clippy --workspace --all-targets --locked -- -D warnings` passed through `scripts/linux-qa.sh shell`. Formatting and Clippy also passed natively on macOS.
- Ran `imacs queue --class test -- scripts/linux-qa.sh test` once. All 179 core tests and 11 integration tests passed; two of 153 application tests exposed equal-mtime config reloads and GNU cp's special-file handling. Both implementations and regression fixtures were corrected. A subsequent queued run of the affected application and git groups passed **153 application tests and 20 git tests**, with no failures. The full workspace suite was not repeated.
- `imacs queue --class qa -- scripts/linux-qa.sh screenshot /private/tmp/imacs-linux-support.png` produced a 1600×1000 PNG. Visual inspection confirmed the steer bar reads **Ctrl+Shift+L focuses**, with working fonts, terminal, icon and layout.
- The release installer lifecycle ran through `scripts/linux-qa.sh shell` with a disposable HOME containing spaces. Install and reinstall ran the native release binary successfully; reinstall changed its inode, confirming atomic replacement. Desktop entry quoting, SVG and 512px PNG icons, custom/default XDG data paths, repeated uninstall, preserved config/session files and absence of staging-file leftovers all passed.
- Additional live QA ran through `imacs queue --class qa -- scripts/linux-qa.sh shell`, without IMACS path overrides or `$SHELL`. It verified XDG state/config locations, a live mode-0600 control socket, a mode-0600 FIFO inside a mode-0700 `jobserver/`, socket exclusion from that writable directory, and a functioning default shell. Launch tests also verified that neither the actual socket nor the default runtime socket is under any generated Codex `--add-dir`.
- The Linux executable-update regression passed: it atomically replaces a running test executable, resolves the installed replacement despite `/proc/self/exe`'s deleted suffix, and validates the restart target. State compatibility/migration and invalid XDG runtime cases passed, as did real process ancestry and agent FIFO/niceness inheritance.
- The native reflink test passed with `IMACS_COW_TEST_DIR=/target` (ext4) and `/dev/shm` (tmpfs). Both reported unsupported reflinks and left no partial destination or staging directory. The full suite exercised the overlay filesystem too. Separate btrfs/XFS mounts were unavailable; their native success paths were not measured here. The clone-only command, independent-file checks and clean-skip behavior remain covered by the portable tests.

The screenshot uses X11/Xvfb with Mesa's Vulkan software renderer. Wayland is compiled in but was not exercised with a Wayland compositor. The requested macOS cross-check was attempted before the harness existed; that host lacks the `x86_64-unknown-linux-gnu` standard library, so native Linux harness checks provided the Linux validation instead.

Host evidence is in `/private/tmp/imacs-linux-support.png` and `/private/tmp/imacs-linux-support-{screenshot,installer,xdg,clone,tests,fixes,affected-tests}.log`. `tests.log` records the initial two failures; `fixes.log` and `affected-tests.log` record their passing regressions and final affected-group checks.
